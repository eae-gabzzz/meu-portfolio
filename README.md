# Gabriel Balbino — Portfólio

Portfólio pessoal responsivo em HTML, CSS e JavaScript puro.

## Recursos
- Identidade visual em preto e azul, com variações azuis nos modos escuro e claro
- Botão PT/EN para trocar o idioma
- Cursor azul com sinal de +, anel suavizado e halo luminoso em desktop
- Animação de texto, entrada de seções, barra de progresso, cards interativos e ticker animado
- Respeito à preferência de redução de movimento do sistema
- Menu responsivo para celular
- Retrato recortado e transparente em `assets/gabriel.png`; a foto original `assets/gabriel.jpg` foi preservada
- Terminal interativo com comandos baseados nas informações do portfólio e modais com detalhes dos projetos
- Idioma preferido salvo no navegador
- Links para WhatsApp, Instagram, LinkedIn e GitHub

## Como executar
Abra `index.html` no navegador. Para desenvolvimento, use a extensão Live Server no VS Code.

## Currículo em PDF
O botão de download usa o currículo fornecido em `assets/cv/gabriel-balbino-cv.pdf`.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `gabriel-balbino-portfolio`.
2. Envie os arquivos e a pasta `assets` para a raiz do repositório.
3. Vá em Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione `main` e `/ (root)`, depois Save.

## Antes de divulgar
- Confira se o WhatsApp está correto.
- Revise as descrições e o status de cada projeto.
- Adicione links individuais para os projetos quando os repositórios/demos estiverem públicos.
- Confirme os nomes oficiais e certificados dos cursos.

Não há backend nem chaves de API no portfólio estático. Não publique segredos em repositórios públicos.
